# Third-party research and compatibility references

Veyra Root uses public repositories as **research evidence** and compatibility references. A repository listed here is not automatically a Veyra payload feed and is not automatically proof that Veyra can run its exploit on every device in the repository's kernel family.

## Root/kernel research

- **p2p3p/GhostLock-for-OnePlus** — OnePlus GhostLock device tables and per-kernel adaptation research.
- **NanoTurtle1145/root-my-s24** — Samsung S24 firmware-specific target-generation research.
- **yakidango-official/GhostLock-H80GT** — Honor 80 GT / AGT-AN00 kernel 5.10 research.
- **JoinChang/ghostlock-oneplus** — OnePlus multi-device / 6.12-family GhostLock research.
- **sarabpal-dev/IonStack-S22U** — Samsung 5.10 target-generation research.
- **zenyxx-xd/RootMyVivo** and **RootMyVivo-Payloads** — vivo/iQOO exact-kernel catalog and payload-state research.
- **ZProtons/android_kernel_vivo_kona** — vivo Kona / SM8250 kernel source evidence.
- **XiaoBaiLovesStirring/ghostlock-k419-adapter** — public Linux 4.19.152-perf+ adapter evidence.

## Permission/ADB compatibility research

- **rushiranpise/Shizuku-Next v14.0.13-next** — Wireless ADB/start-method, permission-management and networking behavior research.

Veyra does not present these projects as its own work. Research-only source entries use an empty Veyra runnable manifest until an exact Veyra-compatible payload definition exists.
